> **🔐 Advanced Password Strength Checker with Crack Time Estimation & Breach Detection**

## 📋 Overview

Morny Password Kit is a secure, feature-rich password strength checker that helps you evaluate password security, estimate crack times, detect breaches, and generate strong passwords - all without storing any passwords.

## 🔥 Features

- ✅ **Password Strength Analysis** - Entropy calculation with detailed breakdown
- ✅ **Crack Time Estimation** - Online, offline, and cloud attack speeds
- ✅ **Breach Detection** - Check against HaveIBeenPwned database
- ✅ **Pattern Detection** - Identifies weaknesses and common patterns
- ✅ **Random Password Generation** - Secure, customizable passwords
- ✅ **Memorable Password Generation** - Easy to remember but strong
- ✅ **No Password Storage** - All analysis is local and temporary
- ✅ **No Data Retention** - Passwords are never saved
